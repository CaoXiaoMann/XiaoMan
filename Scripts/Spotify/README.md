# Spotify Premium 解锁

Spotify 部分解锁 Premium 功能，Loon 插件格式，兼容 Egern / Surge / Loon。

## 功能

- 去除播放广告
- 歌手/专辑列表正常展示
- 去除随机播放限制
- 部分解锁 Premium（音质不能设置为超高）

## 插件链接

```
https://raw.githubusercontent.com/CaoXiaoMann/XiaoMan/main/Scripts/Spotify/spotify.plugin
```

## Egern / Loon 导入

插件标签页 → 点击 + → 粘贴插件链接

## 注意

- 建议登录 Spotify 后再打开脚本
- 导入后重启 App，等待脚本生效
- 2026.04.15 测试可用
