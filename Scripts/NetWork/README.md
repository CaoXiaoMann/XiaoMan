# Network-Pro（网络诊断雷达小组件）

🛡️ 桌面小组件：网络诊断雷达（实时全量刷新 + 释放 IPv6 落地版），解锁落地出口的 IPv6 限制，适配双栈/纯 v6 代理节点。

## 脚本链接


在 **Egern 小组件编辑** 里添加脚本。

## 功能特性

- 🛡️ 实时网络诊断雷达
- 🔄 实时全量刷新
- 🌐 释放 IPv6 落地出口限制
- 🔀 适配双栈 / 纯 v6 代理节点
- 📱 全 iPhone 机型适配
