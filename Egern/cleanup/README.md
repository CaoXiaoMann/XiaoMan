# App & 小程序净化合集（Egern）

由 [wool_scripts](https://github.com/fmz200/wool_scripts) 的 Quantumult X 配置适配而来。

## 使用

在 Egern 主配置中引用：

```yaml
modules:
  - name: "App & 小程序净化合集"
    url: "https://raw.githubusercontent.com/CaoXiaoMann/XiaoMan/main/Egern/cleanup/cleanup.egern.yaml"
    update_interval: 86400
    enabled: true
```

需要安装并启用 Egern MITM 证书。遇到 App 功能异常时，请先禁用本模块。
